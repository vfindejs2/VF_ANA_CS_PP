Grafický editor návrhu

Pracovní HTML pro průchod modelem. Můžeš upravovat Mermaid zdroj, klikat přímo do náhledu a postupně vracet změny zpět do markdown návrhu řešení.

Jak s tím pracovat

  • Vyber diagram vlevo.
  • Klikni v náhledu na název entity nebo popisek vazby a uprav ho v inspektoru.
  • V režimu vazeb můžeš tahem měnit napojení na hranu entity, pozici kardinálů i lomové body spojnice.
  • Pro složitější zásahy uprav Mermaid zdroj ve středním panelu.
  • Undo a redo vrací změny v aktuálním pohledu.
  • Stav můžeš uložit přímo zpět do HTML souboru.

Workflow promítnutí do markdownu

  1. Vyber pohled a uprav diagram tak, aby seděly entity, texty a vazby.
  2. Do poznámek zapisuj změny ve tvaru: Sekce markdown / Co změnit / Proč.
  3. Po stabilizaci ulož stav do HTML, aby zůstala pracovní verze diagramu zachovaná.
  4. Do markdown návrhu pak promítej změny v pořadí: Grafický přehled, Synchronizační rámec, detail entit, otevřené body.
  5. Po propsání do markdownu proveď ještě jedno review, zda diagram a text zůstaly konzistentní.

Poznámka k renderu

Soubor používá Mermaid z CDN. Pokud by se diagram nenačetl, otevři HTML v prostředí s přístupem na internet nebo ve VS Code Simple Browser.

Souhrnný pohled

Hlavní orientační diagram pro rychlou kontrolu celého návrhu datového modelu CS.

Jak kontrolovat: Začni tady. Ověř, že sedí hlavní entity, směry vazeb a logika kolem RPO, Okruhu, Rozvrhu, Zóny a Nádoby.

JSON export ukládá Mermaid zdroj, poznámky, zoom i vizuální kategorie entit. Uložení do HTML zapíše stejný stav přímo do tohoto workbenche.
